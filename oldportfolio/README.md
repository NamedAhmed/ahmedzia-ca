# Ahmed Zia — portfolio

A one-page portfolio: a CRT monitor with a live terminal showing the name, then a tall golden tree you scroll down, with a project on each branch and ranked films, books and games beside the trunk.

## Run

```bash
npm install
npm run dev
```

Open http://localhost:3000.

## Where things are

| Path | What it is |
|---|---|
| `content/site.ts` | Every word and link on the site: projects, ranked lists, contact links. Edit content here. |
| `components/CrtMonitor.tsx` | The hero. A rendered monitor image with the terminal drawn over its screen in HTML and CSS. |
| `components/Erdtree.tsx` | The tree section. Cards are pinned onto the render by percentage. |
| `app/globals.css` | Colours, fonts and the page-level styles. |
| `public/images/` | The two renders the site uses. |
| `blender/` | The Blender scenes and the Python scripts that generate and render them. |

## Changing the 3D

Both images are generated by scripts, so they can be rebuilt after a change.

```bash
# the tree: build the scene, then render it (the render takes about ten minutes)
blender --background --python blender/run_build.py
blender --background blender/erdtree.blend --python blender/render_erdtree.py

# the monitor: builds, saves and renders in one go, and prints the screen's position
blender --background --python blender/build_crt.py
```

After re-rendering, copy `blender/erdtree.jpg` to `public/images/erdtree.jpg`, and convert `blender/crt_monitor.png` to `public/images/crt-monitor.webp`.

### How the bark works

The trunk, main limbs and roots are one fused mesh (object `Erdtree`). The bark comes from a scanned pine bark height map and is real geometry, applied in two layers you can see in the object's modifier stack:

1. **Subdivide**, then **Bark** (a Displace modifier): pushes a blurred copy of the scan into the mesh. This is the part visible in Blender's viewport, and the modifier's Strength controls how far the plates stand out.
2. **Fine detail (render)**: an adaptive subdivision that splits faces down to about a pixel when rendering, so the material can displace the sharp plate edges and fine cracks the blurred copy left out.

The settings worth playing with are at the top of `blender/build_erdtree.py`: `TILE_W` (plate size), `TILE_ASPECT` (how tall the plates are) and `BARK_DEPTH` (relief).

### Credits

The bark scan is [Pine Bark](https://polyhaven.com/a/pine_bark) from Poly Haven, licensed CC0. Its height and colour maps are in `blender/textures/`.

Two things depend on the renders and need updating if they change:

- The project cards' positions in `content/site.ts` follow the tree's branches.
- The `.screen` rule in `components/CrtMonitor.module.css` uses the `SCREEN_RECT` numbers that `build_crt.py` prints.
